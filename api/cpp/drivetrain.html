Constructor(s)

Initializing the drivetrain Class

A drivetrain is created by using the following constructor:

The drivetrain constructor creates a drivetrain object.

Motors and/or Motor Groups must be created first before they can be used to create an object with the drivetrain Class constructor.

If making a 4-Motor Drivetrain, you need to create the Motors separately before grouping them into a Motor Group.

This Drivetrain object will be used in all subsequent examples throughout this API documentation when referring to drivetrain class methods.

To incorporate an Inertial Sensor or Gyro Sensor for enhanced turning functionality in your drivetrain, you can include it when creating an object using the smartdrive Class constructor.

Prototype
Example 
drivetrain();
// Create the Motors.
motor left_motor = motor(PORT1,false);
motor right_motor = motor(PORT2, true);
// Construct a 2-Motor drivetrain "Drivetrain" with the
// drivetrain class.
drivetrain Drivetrain = drivetrain(left_motor, right_motor, 259.34, 320, 40, mm, 1);
Parameters 
lm The name of the Left Motor or Motor Group.
rm The name of the Right Motor or Motor Group.
wheelTravel The circumference of the driven wheels. The default is 300 mm.
trackWidth The track width of the drivetrain. The default is 320 mm.
wheelBase The wheel base of the Drivetrain. The default is 320 mm.
units A valid distanceUnit for the units that wheelTravel, trackWidth and wheelBase are specified in. The default is MM.
externalGearRatio The gear ratio used to compensate drive distances if gearing is used.

Movement Functions

drive() Non-Waiting

This is a non-waiting method and allows the next method to run without delay.

This method is called in the following ways:

The drive(directionType dir) method is used to drive the drivetrain in the specified direction forever at the default velocity as specified by the setDriveVelocity() method, until another drivetrain movement method is used, or the project is stopped.

The drive(directionType dir, double velocity, velocityUnits units) method is used to drive the drivetrain in the specified direction forever at a specified velocity, until another drivetrain movement method is used, or the project is stopped.

Parameters

Description

dir

A valid directionType.

velocity

The velocity at which the drivetrain will move.

units

A valid velocityUnit.

Prototype
Example 
void drivetrain::drive( vex::directionType dir );
void drivetrain::drive( vex::directionType dir, double velocity, vex::velocityUnits units );
// Drive the drivetrain forward.
Drivetrain.drive(forward);
Parameters 
dir A valid directionType.

Returns: None.

driveFor() Non-Waiting

This can be a waiting or non-waiting method depending on if the wait parameter is used.

This method is called in the following ways:

The driveFor(double distance, distanceUnits units, bool waitForCompletion) method is used to drive the drivetrain for a specified distance at the default velocity.

The driveFor(directionType dir, double distance, distanceUnits units, bool waitForCompletion) method is used to drive the drivetrain in a specified direction for a specified distance at the default velocity.

Parameters

Description

dir

A valid directionType.

distance

The distance for the drivetrain to move.

units

A valid distanceUnit. The default is inches.

waitForCompletion

Determines whether the command will block subsequent commands (wait=true) or allow immediate execution (wait=false). If unspecified, the default for the wait parameter is wait=true.

The driveFor(double distance, distanceUnits units, double velocity, velocityUnits units_v, bool waitForCompletion) method is used to drive the drivetrain for a specified distance at the default velocity.

Parameters

Description

distance

The distance for the drivetrain to move.

units

A valid distanceUnit. The default is inches.

velocity

The velocity the drivetrain will move with. The default velocity set by the setDriveVelocity() method will be used if not provided.

units_v

A valid velocityUnit. The default is rpm.

waitForCompletion

Determines whether the command will block subsequent commands (wait=true) or allow immediate execution (wait=false). If unspecified, the default for the wait parameter is wait=true.

The driveFor(directionType dir, double distance, distanceUnits units, double velocity, velocityUnits units_v, bool waitForCompletion) method is used to drive the drivetrain for a specified distance at the default velocity.

Parameters

Description

dir

A valid directionType.

distance

The distance for the drivetrain to move.

units

A valid distanceUnit. The default is inches.

velocity

The velocity the drivetrain will move with. The default velocity set by the setDriveVelocity() method will be used if not provided.

units_v

A valid velocityUnit. The default is rpm.

waitForCompletion

Determines whether the command will block subsequent commands (wait=true) or allow immediate execution (wait=false). If unspecified, the default for the wait parameter is wait=true.

Prototype
Example 
bool drivetrain::driveFor( double distance, vex::distanceUnits units, bool waitForCompletion );
bool drivetrain::driveFor( vex::directionType dir, double distance, vex::distanceUnits units, bool waitForCompletion );

The turn(turnType dir, double velocity, velocityUnits units) method is used to turn the robot in a specified direction at a specified velocity, until another drivetrain movement method is used, or the project is stopped.

stop() Non-Waiting

This is a non-waiting command and allows the next command to run without delay.

This method is called in the following ways:

The stop() command is used to stop the drivetrain, setting the drivetrain to 0 velocity and configuring the current stopping mode. The default Brake Type is coast, unless previously changed using the setStopping() command.

The stop(brakeType mode) command is used to stop the drivetrain using a specific Brake Type.

Prototype
Example 
void drivetrain::stop();
void drivetrain::stop( vex::brakeType mode );
// Spin Drivetrain for 2.5 seconds.
Drivetrain.spin(forward);

wait(2.5 seconds);

// Stop Drivetrain.
Drivetrain.stop();
Parameters 
mode A valid brakeType.

Returns: None.

setDriveVelocity()

The setDriveVelocity(double velocity, velocityUnits units) method is used to set the default velocity for the Drivetrain. This velocity setting affects all subsequent drive method unless a specific velocity is provided in those method.

Prototype
Example 
void drivetrain::setDriveVelocity( double velocity, vex::velocityUnits units );
// Set the drivetrain to drive at a velocity of 200 rpm.
Drivetrain.setDriveVelocity(200, rpm);
Parameters 
velocity The new velocity to set as default for the Drivetrain.
units A valid velocityUnit or percent. The default is rpm.

Returns: None.

setTurnVelocity()

The setTurnVelocity(double velocity, velocityUnits units) method is used to set the default velocity for turning maneuvers in the Drivetrain. This setting specifies the speed at which the drivetrain will execute turning method unless overridden by a specific velocity in those method.

Prototype
Example 
void drivetrain::setTurnVelocity( double velocity, vex::velocityUnits units );
// Set the drivetrain to turn at a velocity of 200 RPM.
Drivetrain.setTurnVelocity(200, rpm);
Parameters 
velocity The new velocity to set as default for turning maneuvers.
units A valid velocityUnit or percent. The default is rpm.

Returns: None.

setStopping()

The setStopping(mode) method is used to set the stopping mode for all motors on the Drivetrain. This setting determines the behavior of the motors when they receive a stop method or when the velocity is set to zero.

Prototype
Example 
void drivetrain::setStopping( vex::brakeType mode );
// Set the stopping mode to BRAKE.
Drivetrain.setStopping(brake);
Parameters 
mode A valid brakeType.

Returns: None.

setTimeout()

The Drivetrain.setTimeout(int32_t time, timeUnits units) method is used to set the timeout value for all motors on the Drivetrain. This setting determines how long the drivetrain will attempt to execute driveFor or turnFor method before timing out if the motors have not completed their movements.

Prototype
Example 
void drivetrain::setTimeout( int32_t time, vex::timeUnits units );
// Set the timeout for the drivetrain to 10 seconds.
Drivetrain.setTimeout(10, seconds);
Parameters 
timeout The timeout duration to set as default for drivetrain operations.
units A valid timeUnit type. The default is msec.

Returns: None.
