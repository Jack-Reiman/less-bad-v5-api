Constructor(s)

Initializing the pneumatic Class

A Pneumatic System is created by using the following constructor:

The pneumatic constructor creates a pneumatic object in the specified Port.

This Pneumatic object will be used in all subsequent examples throughout this API documentation when referring to pneumatic class methods.

Prototype
Example 
vex::pneumatics( int32_t port );
// Construct a Pneumatic System "Pneumatic" with the
// pneumatic class.
pneumatic Pnuematic = pneumatic(PORT1);
Parameters 
port A valid Smart Port that the Pneumatic Solenoid is connected to.
pumpEnable A boolean value representing whether to enable or disable the air pump.

Telemetry Functions

installed()

The installed() method checks for device connection.

Prototype
Example 
void pneumatics::installed();
// No example provided in official VEXcode API.

Returns: true if the device is connected. false if it is not.

Functions

retract()

The retract(cylinderType) method retracts a cylinder.

Prototype
Example 
void pneumatics::retract();
// Extend the first cylinder.
Pneumatic.extend(cylinder1);

// Wait 2 seconds.
wait(2, seconds);

// Retract the first cylinder.
Pneumatic.retract(cylinder1);
Parameters 
cylinderType A valid cylinderType.

Returns: None.

pumpOn()

The pumpOn() method turns the pneumatic air pump on.

Prototype
Example 
void pneumatics::pumpOn();
// Turn air pump on.
Pneumatic.pumpOn();

Returns: None.

pumpOff()

The pumpOff() method turns the pneumatic air pump off.

Prototype
Example 
void pneumatics::pumpOff();
// Turn air pump off.
Pneumatic.pumpOff();

Returns: None.

pump()

The pump(state) method turns the pneumatic air pump on or off.

Prototype
Example 
void pneumatics::pump();
// Turn air pump on.
Pneumatic.pump(true);

wait(3, seconds);

// Turn air pump off.
Pneumatic.pump(false);
Parameters 
state The compressor state. true to turn it on. false to turn it off.

Returns: None.

timestamp()

The timestamp() method requests the timestamp of the last received status packet from the Pneumatics System.

Prototype
Example 
int32_t pneumatics::timestamp();
// No example provided in official VEXcode API.

Returns: Timestamp of the last status packet as an unsigned 32-bit integer in milliseconds.
