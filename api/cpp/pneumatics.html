Pneumatics C++ API

Hardware Specification

Class: vex::pneumatics  |  Port: 3-Wire Port A-H  |  Competition Status: V5RC Legal Hardware  |  Header: #include "vex.h"

V5RC Competition Pneumatics Note

In the VEX V5 Robotics Competition (V5RC), pneumatic systems use manual air reservoir tanks pre-charged before the match with a bicycle hand pump (up to 100 PSI maximum). Motorized air compressors and pumps are strictly illegal under competition rule <R18>.

Pneumatic cylinders are actuated by 5V solenoid valves connected to the Brain's 3-Wire (ADI) Ports (A–H) or an external 3-Wire Expander. Solenoids can be controlled using this dedicated vex::pneumatics class, or configured as a vex::digital_out device in the VEXcode Devices window.

Functions

Constructor(s)

pneumatics()

Creates a new pneumatics object connected to the specified 3-Wire (ADI) Port on the V5 Brain or a 3-Wire Expander.

This Piston object will be used in subsequent examples throughout this API documentation when referring to pneumatic class methods.

Prototype
Example 
vex::pneumatics( vex::triport::port &port );
// Create the Brain.
brain Brain;

// Construct a Pneumatic Cylinder on 3-Wire Port A.
vex::pneumatics Piston = vex::pneumatics(Brain.ThreeWirePort.A);

// Alternatively, construct on a 3-Wire Expander on Smart Port 20:
vex::triport Expander = vex::triport(vex::PORT20);
vex::pneumatics Piston2 = vex::pneumatics(Expander.A);
Parameters 
portThe 3-Wire Port that the pneumatic solenoid driver cable is connected to, whether on the Brain (e.g. Brain.ThreeWirePort.A) or on a 3-Wire Expander.

Movement Functions

extend()

The extend() method actuates the pneumatic solenoid to extend the pneumatic cylinder by supplying 5V power.

Prototype
Example 
void vex::pneumatics::extend();
// Extend the pneumatic cylinder.
Piston.extend();

Returns: None.

retract()

The retract() method de-actuates the pneumatic solenoid to retract the pneumatic cylinder by removing power.

Prototype
Example 
void vex::pneumatics::retract();
// Retract the pneumatic cylinder.
Piston.retract();

Returns: None.

open()

The open() method opens the pneumatic cylinder. This is functionally identical to extend().

Prototype
Example 
void vex::pneumatics::open();
// Open the pneumatic claw mechanism.
Piston.open();

Returns: None.

close()

The close() method closes the pneumatic cylinder. This is functionally identical to retract().

Prototype
Example 
void vex::pneumatics::close();
// Close the pneumatic claw mechanism.
Piston.close();

Returns: None.

set()

The set(value) method sets the active state of the pneumatic solenoid. Passing true extends/opens the cylinder, and passing false retracts/closes the cylinder.

Prototype
Example 
void vex::pneumatics::set( bool value );
// Extend while button L1 is held, retract when released.
if (Controller1.ButtonL1.pressing()) {
    Piston.set(true);
} else {
    Piston.set(false);
}
Parameters 
valueBoolean state: true to extend / open the cylinder, false to retract / close the cylinder.

Returns: None.

toggle()

The toggle() method toggles the pneumatic cylinder between extended and retracted states.

Prototype
Example 
void vex::pneumatics::toggle();
// Toggle the cylinder state when Button A is pressed.
Controller1.ButtonA.pressed([]() {
    Piston.toggle();
});

Returns: None.

Telemetry Functions

value()

The value() method returns the current state of the pneumatic solenoid output.

Prototype
Example 
int32_t vex::pneumatics::value();
// Display whether the cylinder is extended.
if (Piston.value()) {
    Brain.Screen.print(""Cylinder is Extended"");
} else {
    Brain.Screen.print(""Cylinder is Retracted"");
}

Returns: int32_t: 1 if the cylinder is currently extended/energized, 0 if retracted/de-energized.
