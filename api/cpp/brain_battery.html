Movement Functions

voltage()

The voltage(units) method reports the voltage of the battery.

Prototype
Example 
void Brain.Battery::voltage( vex::rotationUnits units = vex::rotationUnits::deg );
// No example provided in official VEXcode API.
Parameters 
units A valid VoltageUnits type. The default is volt.

Returns: The voltage in the supplied units.

Prototype

void Brain.Battery::temperature( vex::rotationUnits units = vex::rotationUnits::deg );
// No example provided in official VEXcode API.
