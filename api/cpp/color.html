Initializing the color Class

A color is created by using one of the following constructors:

The color(r, g, b) constructor creates a color using rgb values:

The color(value) constructor creates a color using rgb values:

Parameter

Description

value

A hexcode value or a predefined colorType.

This Yellow object will be used in all subsequent examples throughout this API documentation when referring to Color class methods.

Prototype
Example 
color( auto r, auto g, auto b );
// Construct a yellow color "Yellow" with the color class 
// using rgb values.
color Yellow = color(255, 247, 0);
Parameters 
r An integer in the range 0 to 255 representing the red value.
g An integer in the range 0 to 255 representing the green value.
b An integer in the range 0 to 255 representing the blue value.

Telemetry Functions

isTransparent()

The isTransparent() method returns if the color is transparent or not.

Prototype
Example 
vex::color color::isTransparent();
// No example provided in official VEXcode API.

Returns: true if the color is transparent. false if it is not.

hue()

The hue() method returns the hue of the color.

Prototype
Example 
vex::color color::hue();
// No example provided in official VEXcode API.

Returns: The hue of the color in the range 0 - 360 degrees.

brightness()

The brightness() method returns the brightness of the color.

Prototype
Example 
vex::color color::brightness();
// No example provided in official VEXcode API.

Returns: The brightness of the color in the range 0 - 1.0.

Functions

hsv()

The hsv(hue, saturation, value) method changes the existing color instance using hsv.

Prototype
Example 
int32_t color::hsv( auto hue, auto saturation, double value );
// Change Yellow to a color that is red using HSV values.
Yellow.hsv(0, 1.0, 1.0);
Parameters 
hue An integer from 0 - 360 that represents the hue of the color.
saturation A double from 0.0 - 1.0 that represents the saturation of the color.
value A double from 0.0 - 1.0 that represents the brightness of the color.

Returns: An integer value representing the color.

web()

The web(value) method changes the existing color instance using webstring.

Prototype
Example 
int32_t color::web( double value );
// Change Yellow to a color that is red using a Hexcode.
Yellow.web("#ff0000");
Parameters 
value The color value in web format.

Returns: An integer value representing the color.

saturation()

The saturation() method returns the saturation of the color.

Prototype
Example 
vex::color color::saturation();
// No example provided in official VEXcode API.

Returns: The saturation of the color in the range 0 - 1.0.
