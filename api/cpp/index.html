V5RC Competition Legal Hardware Reference

Welcome to the VEXcode V5 C++ API Reference. Select any competition-legal hardware component, sensor, or system module below to inspect full function prototypes, parameter tables, execution wait semantics, and verified example code.

Actuators & Motors

Motor (11W) →

Smart Port 1-21 vex::motor

V5 11W Smart Motor with integrated encoder and current, torque, temperature telemetry.

Motor 5.5W →

Smart Port 1-21 vex::motor

V5 5.5W Smart Motor designed for lightweight mechanisms and compact designs.

Motor Group →

Multiple Smart Ports vex::motor_group

Synchronized multi-motor control group for lifts, intakes, and drivetrains.

Drivetrain

Drivetrain →

2 or 4 Smart Motors vex::drivetrain

Standard 2-motor or 4-motor differential drivetrain with distance and turn tracking.

SmartDrive →

Drivetrain + Inertial vex::smartdrive

Inertial-assisted drivetrain offering precision heading turns and gyro correction.

Brain & Controller

Brain →

V5 Brain vex::brain

V5 Brain core device providing access to screen, battery, timer, and SD card.

Brain Screen →

V5 Touchscreen Brain.Screen

Full-color touchscreen graphics, shape rendering, text printing, and touch events.

Brain Battery →

V5 Battery Brain.Battery

Battery telemetry including voltage, current draw, temperature, and percentage capacity.

Brain SD Card →

MicroSD Slot Brain.SDcard

File system access for reading and writing files to the micro-SD card.

Timer →

System Timer vex::timer

High-precision timer for elapsed time measurement and benchmarking.

Controller →

V5 Controller vex::controller

V5 handheld remote controller interface for sticks, buttons, and screen.

Controller Axis →

Joysticks Controller.Axis

Analog joystick channels (Axis1, Axis2, Axis3, Axis4) with position and callbacks.

Controller Button →

Buttons Controller.Button

Digital controller buttons (L1, L2, R1, R2, Up, Down, Left, Right, A, B, X, Y).

Controller Screen →

LCD Display Controller.Screen

Handheld controller screen text printing, cursor positioning, and line clearing.

Smart Sensors

Inertial Sensor →

Smart Port 1-21 vex::inertial

3-axis accelerometer and 3-axis gyroscope with sensor-fusion heading, pitch, roll, and yaw.

Optical Sensor →

Smart Port 1-21 vex::optical

Ambient light, color hue, proximity, gesture detection, and white LED illumination.

Distance Sensor →

Smart Port 1-21 vex::distance

Time-of-flight laser distance sensor measuring millimetric range and object velocity.

Rotation Sensor →

Smart Port 1-21 vex::rotation

High-resolution absolute and relative shaft encoder with position and angular velocity.

GPS Sensor →

Smart Port 1-21 vex::gps

Game Field Positioning System sensor tracking absolute X/Y field coordinates and heading.

AI Vision Sensor →

Smart Port 1-21 vex::aivision

AI-powered vision sensor identifying game objects, AprilTags, and color codes.

Vision Sensor →

Smart Port 1-21 vex::vision

Color-signature tracking camera detecting game objects, sizes, and coordinates.

3-Wire (ADI) Devices

TriPort (ADI) →

3-Wire Ports A-H vex::triport

TriPort expander and built-in 3-wire ports for competition-legal 3-wire sensors and actuators.

Pneumatics →

3-Wire Port A-H vex::pneumatics

V5 Pneumatics cylinder solenoid control (extend, retract, open, close, set, toggle, value) via 3-wire ADI ports.

Digital Out →

3-Wire Port A-H vex::digital_out

3-Wire digital output control for pneumatic solenoids, relays, and custom electronics.

Digital In →

3-Wire Port A-H vex::digital_in

3-Wire digital input line with high/low state change event callbacks.

Bumper Switch →

3-Wire Port A-H vex::bumper

Physical mechanical bumper switch detecting contact and presses.

Limit Switch →

3-Wire Port A-H vex::limit

Physical micro-switch limit sensor for mechanical stops.

Line Tracker →

3-Wire Port A-H vex::line

Infrared reflectance sensor detecting field line tape and contrast.

Encoder →

3-Wire Ports (Pairs) vex::encoder

Optical quadrature shaft encoder using two digital ports for rotation tracking.

Potentiometer →

3-Wire Port A-H vex::potentiometer

Analog rotary potentiometer measuring up to 250 degrees of shaft position.

Potentiometer V2 →

3-Wire Port A-H vex::potentiometerV2

V2 330-degree rotary potentiometer with enhanced linearity.

Analog In →

3-Wire Port A-H vex::analog_in

General-purpose analog sensor input with voltage reading and changed callbacks.

LED Indicator →

3-Wire Port A-H vex::led

3-Wire colored LED status indicator with on, off, and toggle methods.
