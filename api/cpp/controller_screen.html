Movement Functions

setCursor()

The setCursor(row, col) method sets the cursor position used for printing text on the screen.

The V5 controller can display at most 3 lines of text.

Prototype
Example 
void Controller.Screen::setCursor();
// No example provided in official VEXcode API.
Parameters 
row The cursor row: 1, 2, or 3.
col The cursor column. The first column is 1.

Returns: None.

print()

The print(value, format, ...) method prints text on the screen using the current cursor position.

Prototype

clearLine()

There are two ways to clear a line on the Controllerâ€™s screen.

The clearLine() method clears the row that the cursor is currently on.

The clearLine(row) method clears the specified row.

Prototype
Example

// Clear row 2.

Parameters 
row The row to clear: 1, 2, or 3.

Returns: None.
