# Less Bad V5 API

A clean, developer-focused redesign of the official **VEXcode V5 C++ API documentation**, styled after the **Purdue PROS** documentation.

### Features
- **Official VEXcode V5 C++ API**: Accurate C++ function prototypes, parameter tables, execution wait semantics, and code snippets sourced directly from official VEX Robotics documentation.
- **PROS Stylization**: Full dark mode, Purdue gold accents, compact responsive method grids, Sphinx-style prototype/example tabs, and Docutils parameter tables.
- **V5RC Legal Hardware Only**: Curated to 36 competition-legal components across 8 categories.
- **Client-Side Instant Search**: Built-in modal search indexing 380+ methods and classes.
